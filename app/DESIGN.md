# DESIGN.md

## 氣質與意象

「清晨書桌上的一枚溫潤鵝卵石」——安靜、有觸感、被晨光照亮。界面是一張未漂白的棉紙，中央一枚墨色圓形麥克風按鈕是唯一視覺焦點，像桌面上那枚等你拾起說話的石頭。整體是一位不說話時完全隱形的私人秘書。

## 視覺策略

- 大量留白；列表不用卡片堆砌，像筆記本上的橫行，用 1px 細線分隔
- 陰影極輕（僅按鈕有一點貼地感），拒絕浮誇的懸浮卡片
- 錄音狀態只通過顏色與漣漪傳達，不加多餘圖標

## 配色方案

- 背景：米白紙色 `#FAF9F6`（意象：未漂白的棉紙）
- 主文字：墨色 `#1C1B1A`（意象：鉛筆字跡）
- 次要文字：暖灰 `#8A8680`
- 麥克風按鈕：墨色圓盤 `#1C1B1A`；錄音中轉為赤陶色 `#C05538`（意象：炭火被點燃）
- 錄音動效：同色漣漪同心圓向外擴散淡出
- 狀態色：已送出＝灰綠 `#6F8266`；失敗＝赤陶紅 `#C05538`；待發送＝暖灰
- 分隔線：`#E8E5DF`

## 字體排版

- 字體族：Noto Sans TC（繁體中文，Google Fonts），fallback PingFang TC / Microsoft JhengHei
- 時間與數字使用 `font-variant-numeric: tabular-nums`
- 層級：大標題 20px/600、正文 15px/400、輔助 13px/400

## 動效與交互

- 統一緩動：`cubic-bezier(0.22, 1, 0.36, 1)`（緩出、有呼吸感）
- 錄音漣漪：2.4s 循環，scale 1→1.8、opacity 0.35→0
- 按鈕按壓：`scale(0.96)`，150ms
- 頁面/面板切換：fade + 8px 上移，250ms

## 布局與響應式

- 手機優先：麥克風按鈕直徑手機 96px / 桌面 112px，位於視覺中心偏上
- 列表最大寬 640px 居中；手機左右留白 20px
- 頂部導航僅：標題 + 通訊錄 / 設置入口（文字按鈕）

## 設計禁忌

- 禁止藍紫漸變、「AI 感」霓虹光效
- 禁止深色模式（本產品只有淺色）
- 禁止重陰影與擬物高光
- 禁止 emoji 作為 UI 圖標（用 Lucide 圖標）
- 禁止圓角卡片堆疊式布局
